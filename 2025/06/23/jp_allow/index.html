OS Ubuntu
Version 24.04.2 LTS

hosts.allowとhosts.denyの設定

最終行は改行が必要です（改行がないと正常に動作しません）

/etc/hosts.allow

/etc/hosts.deny

スクリプト

必要なライブラリの取得します

jp_allow.py

実行

/etc に書き込むため管理者権限が必要です

hosts.allowとhosts.denyは接続の度に動的に読み込まれるので、別ターミナル等で試行してからセッションを切断してください
